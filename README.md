# Fisher_scallions_weight — 大葱称重上位机软件

> 北京交通大学 · 慧鱼机创赛项目 · 适配 1kg 量程 HX711 TTL 变送器电子秤

实时显示电子秤重量并累计总重，适用于大葱自动分拣场景。基于 Python + Tkinter，支持虚拟测试模式（无需硬件）。

---

## 1. 项目简介

大葱自动称重分拣系统的 PC 端上位机软件。串口连接电子秤后：

- 实时显示当前物品重量（g，1 位小数）
- 自动累计总重，每件物品离开托盘时把峰值加入总重
- 状态机带去抖（5g 启动 / 3g 停止），防止误触发
- 首次连接自动零点校准
- 支持虚拟测试模式：无硬件也能调试业务逻辑

软件 UI 保留 v2 版本的视觉风格（绿色农产品配色、动态粒子背景、仿宋字体、北京交通大学 LOGO）。

## 2. 硬件

### 2.1 电子秤

- **型号**：CMCU-07 称重变送器（TTL 自定义协议 V3.70，1kg 量程，HX711 ADC）
- **淘宝购买链接**：[数字称重变送器 RS485通信MODBUS PLC称重传感器TTL电子秤HX711](https://e.tb.cn/h.R6j4l2jhcZqXUPw?tk=iW6y5zC84vM)
- **通信接口**：TTL（电平 3.3-5.5V）
- **默认参数**：波特率 9600、8 数据位、1 停止位、无校验、模块地址 0
- **分辨率**：1kg 量程推荐按 0.1g 校准（即重量刻度值 × 0.1 = 实际 g）
- **详细资料**：见 `电子秤资料/称重变送器模块（TTL自定义协议）资料下载/`
  - `电子秤串口模块说明书 V3.70___20240308-已解锁.pdf`（核心）
  - `调试软件助手 使用说明书20231112-已解锁.pdf`（PC 端调试工具参考）
  - `操作视频.mp4`（接线与校准演示）
  - `驱动文件/CH340驱动/`（USB 转 TTL 驱动）

### 2.2 接线

```
压力传感器 ──E+/E-/S+/S+──> CMCU-07 变送器
CMCU-07 ──VCC/GND/TXD/RXD──> CH340 USB 转 TTL 模块 ──USB──> PC
```

> 注意：TTL 串口线需要**交叉连接**（变送器 TXD → CH340 RXD，变送器 RXD → CH340 TXD）。本模块是 TTL 接口，**不能直接接 RS232**，会烧坏。

压力传感器颜色定义（常见）：红=E+、黑=E-、白=S-、绿=S+。如颜色定义不同请参考传感器说明书。

## 3. 软件架构

按层次拆分为 8 个模块，便于维护和测试：

```
serial port ──> scale_protocol (帧解析/校验/指令构造)
              ──> scale_driver   (pyserial 封装 + 模拟驱动)
              ──> calibration   (零点/砝码/去皮 高级流程)
              ──> weight_filter (滑动平均 + 稳定判定)
              ──> weight_state  (IDLE/WEIGHING 状态机 + 累计)
              ──> app           (Tkinter UI)
              ──> main          (程序入口 + run_as_admin)
```

| 文件 | 职责 |
|------|------|
| `config.py` | 所有可调常量（波特率、阈值、分辨率、模拟模式开关等） |
| `scale_protocol.py` | 协议层：10 字节帧构造、解析、累加和校验、粘包/拆包 |
| `scale_driver.py` | 驱动层：`ScaleDriver`（真实）+ `SimulatedScaleDriver`（虚拟） |
| `weight_filter.py` | 滤波层：滑动平均 + 稳定值判定 |
| `weight_state.py` | 业务状态机：IDLE / WEIGHING 切换、peak 跟踪、累计 |
| `calibration.py` | 校准管理：零点 / 砝码 / 去皮，自动处理自动发送模式启停 |
| `app.py` | Tkinter UI（主窗口、连接按钮、校准按钮、显示标签、粒子背景） |
| `main.py` | 入口：管理员权限请求 + 启动 Tk 主循环 |

## 4. 安装与运行

### 4.1 环境要求

- Python 3.8+
- Windows（其他系统也能跑，但 `run_as_admin` 仅 Win 有效）
- 串口硬件（CH340 USB 转 TTL 已连接电子秤）

### 4.2 安装依赖

```bash
pip install -r requirements.txt
```

### 4.3 启动

```bash
python main.py
```

Windows 上首次启动会自动以管理员权限重启（UAC 弹窗），以支持全屏与焦点抢获。

### 4.4 虚拟测试模式（无需电子秤）

适合无硬件调试：

1. 编辑 `config.py`，将 `SIMULATE_MODE_DEFAULT` 改为 `True`
2. 运行 `python main.py`
3. 点击"连接"按钮直接进入虚拟模式
4. 程序内部按 0/30g 周期生成符合协议的 10 字节帧，**所有下游逻辑（协议解析→滤波→稳定判定→状态机→累计→UI）都走真实代码路径**
5. 调试完成后改回 `False`

## 5. 使用流程

### 5.1 首次使用（默认流程，**无需砝码**）

1. 连接 USB 转 TTL 模块到电脑，安装 CH340 驱动
2. 启动 `python main.py`
3. 选择串口（CH340 对应 COM 口）→ 波特率（默认 9600）→ 点击"连接"
4. 程序弹出倒计时"请确认托盘已清空，3 秒后自动校准零点..."
5. 等待自动校准完成（约 1 秒），状态栏显示"已连接 · 已自动零点校准"
6. 放上物品即可称重；累计总重自动累加；点击"清零总重"可重置累计

> **重要**：卖家声称电子秤出厂已按 0.1g 分辨率校准（1kg 量程推荐精度），所以**无砝码用户可直接使用**。如长时间使用出现零点漂移，重新连接即可再次自动校准。

### 5.2 高级校准（可选，**需要 500g 砝码**）

如对精度有更高要求：

1. 清空托盘 → 点击 UI 上的"零点校准"
2. 放上 500g 砝码 → 点击"砝码校准" → 输入 500 → 确认
3. 校准完成后取下砝码

> 砝码重量建议 ≥ 量程 20%（即 ≥ 200g），否则校准可能不准确。

### 5.3 校准原理

电子秤内部有两个校准参数：

- **零点**：当前 AD 值的偏移基准。第 3 条指令 `AA 00 A9 AB A8` 永久保存。
- **分度值（分辨率）**：砝码校准决定。第 6 条指令 `AD 00 DHi DLo YY`，其中砝码值 = 砝码重量(g) / 分辨率(g)。例如 500g 砝码按 0.1g 分辨率校准时，砝码值 = 5000 = 0x1388，发送 `AD 00 13 88 36`。

校准期间会先发任意其他指令终止自动发送模式（手册第 12 条提示：模块收到其他任意有效指令后自动发送模式失效），校准完成后再重新启动。

### 5.4 去皮

UI 按钮"去皮"：临时把当前 AD 设为零点，断电丢失。
"取消去皮"：恢复去皮前的 AD 基准。

适用于托盘上放容器后再称量物品的净重。

## 6. 通信协议概要

> 详见 `电子秤资料/.../电子秤串口模块说明书 V3.70___20240308-已解锁.pdf`

### 6.1 帧格式

所有数据均为**十六进制**。读重量帧 10 字节：

| Byte1 | Byte2 | Byte3 | Byte4 | Byte5-7 | Byte8-9 | Byte10 |
|-------|-------|-------|-------|---------|---------|--------|
| 0xAA 起始 | CMD 命令 | ADDR 地址 | SIGN 正负 | WEIGHT 24位 | CHK 校验 | 0xFF 结束 |

- **正负**：0 = 正数，1 = 负数
- **重量刻度值**：`Byte5*65536 + Byte6*256 + Byte7`（24 位无符号）
- **实际 g**：`刻度值 × 分辨率`（默认分辨率 0.1g）
- **校验**：`sum(Byte2..Byte7) == Byte8*256 + Byte9`

### 6.2 关键指令

| 指令 | 命令帧（地址=0） | 功能 |
|------|------------------|------|
| 读重量 | `A3 00 A2 A4 A5` | 模块返回当前重量（最常用） |
| 零点校准 | `AA 00 A9 AB A8` | 取当前 AD 作为零点，永久保存 |
| 去皮 | `AB 00 AA AC AD` | 临时清零（断电丢失） |
| 取消去皮 | `AC 00 AB AD AA` | 恢复去皮前基准 |
| 砝码校准 | `AD 00 DHi DLo YY` | 写入砝码值确定分辨率 |
| 启动自动发送（100ms） | `A4 00 A3 A5 A2` | 模块每 100ms 自动推送重量 |
| 启动自动发送（变化时） | `A4 00 A5 A3 A2` | 重量变化时推送 |

> 所有命令第 5 字节均为前 4 字节的异或校验。

### 6.3 帧解析示例（手册原文）

**举例 1（正数 50g）**：

- 接收：`AA A3 00 00 00 00 32 00 D5 FF`
- 校验：长度=10 ✓，首字节=0xAA ✓，尾字节=0xFF ✓
- 累加和：`A3+00+00+00+00+32 = 0xD5 = 213`
- 期望：`00*256+D5 = 213` ✓
- 重量：`0x00*65536 + 0x00*256 + 0x32 = 50`
- 正负：Byte4=0 → 正数
- **结果：+50g**

## 7. 状态机逻辑

```
IDLE ──(连续2次>5g)──> WEIGHING（跟踪 peak）──(连续2次<3g)──> 累计 peak 到总重 ──> IDLE
```

- **防误触发**：进入 WEIGHING 需连续 2 次 > 5g；退出需连续 2 次 < 3g
- **峰值跟踪**：进入 WEIGHING 后记录 peak_weight（直到物品离开）
- **过滤噪声**：滤波器窗口 5（`config.FILTER_WINDOW_SIZE`）

所有阈值在 `config.py` 中可调。

---

## 8. 注意事项

- 校准期间会自动停止自动发送模式，校准完成后再重启
- 砝码重量建议 ≥ 量程 20%（仅供高级校准用）
- 测量前需保证托盘空载
- TTL 信号传输距离 ≤ 1m（长距离请用 RS485 版本）
- 首次使用**无需砝码**，程序会自动零点校准
- 长时间使用后如出现零点漂移，重新连接即可再次自动校准
- 如累计总重超过 `MAX_TOTAL_GRAMS`（默认 9999g）会被钳制
