# Fisher_scallions_weight — 大葱称重上位机软件

> 北京交通大学 · 慧鱼机创赛项目 · 适配 1kg 量程 HX711 TTL 变送器电子秤

实时显示电子秤重量并累计总重，适用于大葱自动分拣场景。基于 Python + Tkinter，支持虚拟测试模式（无需硬件）。

---

## 1. 项目简介

大葱自动称重分拣系统的 PC 端上位机软件。串口连接电子秤后：

- 实时显示**稳定后的最终重量**（g，1 位小数），不会逐级爬升/下降
- 自动累计总重，每件物品离开托盘时把峰值加入总重
- 状态机带去抖（5g 启动 / 3g 停止），防止误触发
- **每次连接后自动去皮**（把当前重量视为 0 临时基准）
- 支持虚拟测试模式：无硬件也能调试业务逻辑

软件 UI 保留 v2 版本的视觉风格（绿色农产品配色、动态粒子背景、仿宋字体、北京交通大学 LOGO）。

### 1.1 设计原则：分层设置

| 类别 | 工具 | 频次 |
|------|------|------|
| **硬件级设置**（波特率、零点校准、砝码校准等） | 厂商调试软件 `调试软件 V3.70.exe` | 一次性 |
| **会话级操作**（连接、显示、去皮） | 本程序 | 每次运行 |

> 本程序**不提供**硬件级设置功能（如零点校准、砝码校准）。这些操作通过专用调试软件完成，之后永久保存在电子秤中。本程序每次运行时只做"去皮"——把当前重量作为临时零点（断电丢失），适配每次称重前可能存在的容器/托盘。

## 2. 硬件

### 2.1 电子秤

- **型号**：CMCU-07 称重变送器（TTL 自定义协议 V3.70，1kg 量程，HX711 ADC）
- **淘宝购买链接**：[数字称重变送器 RS485通信MODBUS PLC称重传感器TTL电子秤HX711](https://e.tb.cn/h.R6j4l2jhcZqXUPw?tk=iW6y5zC84vM)
- **通信接口**：TTL（电平 3.3-5.5V）
- **默认参数**：波特率 9600、8 数据位、1 停止位、无校验、模块地址 0
- **分辨率**：1kg 量程推荐按 0.1g 校准（即重量刻度值 × 0.1 = 实际 g）
- **详细资料**：见 `电子秤资料/称重变送器模块（TTL自定义协议）资料下载/`
  - `电子秤串口模块说明书 V3.70___20240308-已解锁.pdf`（核心）
  - `调试软件助手 使用说明书20231112-已解锁.pdf`（PC 端调试工具参考）
  - `操作视频.mp4`（接线与校准演示）
  - `驱动文件/CH340驱动/`（USB 转 TTL 驱动）
  - `调试软件/调试软件 V3.70.exe`（**硬件级设置工具**）

### 2.2 接线

```
压力传感器 ──E+/E-/S+/S+──> CMCU-07 变送器
CMCU-07 ──VCC/GND/TXD/RXD──> CH340 USB 转 TTL 模块 ──USB──> PC
```

> 注意：TTL 串口线需要**交叉连接**（变送器 TXD → CH340 RXD，变送器 RXD → CH340 TXD）。本模块是 TTL 接口，**不能直接接 RS232**，会烧坏。

压力传感器颜色定义（常见）：红=E+、黑=E-、白=S-、绿=S+。如颜色定义不同请参考传感器说明书。

## 3. 新电子秤初始设置（首次使用，**必须**用专用调试软件完成）

> 这是一次性操作，完成后参数永久保存在电子秤内，之后正常使用本程序即可。

### 3.1 安装 USB 转 TTL 驱动

首次使用 CH340 模块时需安装驱动：

- 运行 `电子秤资料/.../驱动文件/CH340驱动/CH341SER（CH340驱动）.EXE`
- 完成后在"设备管理器 → 端口"中应能看到 `USB-SERIAL CH340 (COMx)`

### 3.2 连接电子秤

按 §2.2 接线，给变送器供电（DC 3.3-5.5V）。

### 3.3 用厂商调试软件做硬件级设置

打开 `电子秤资料/.../调试软件/调试软件 V3.70.exe`，按以下步骤设置：

| 步骤 | 操作 | 目的 |
|------|------|------|
| ① 选择串口 | 工具栏选择对应 COM 口，波特率选 9600 | 建立通信 |
| ② 零点校准 | 清空托盘 → 发送第 3 条指令 `AA 00 A9 AB A8` | 把当前 AD 设为永久零点 |
| ③ 砝码校准 | 放 500g 砝码 → 发送第 6 条指令（砝码值=5000，0.1g 分辨率） | 设定 0.1g 分辨率 |
| ④ 验证读数 | 砝码应显示 `500.0 g`；取下砝码应显示 `0.0 g` | 确认校准成功 |
| ⑤ （可选）参数调节 | 在"参数设置"中调整：滤波深度、追零范围、动态跟踪等 | 优化稳定性 |

> **完成以上步骤后，电子秤的硬件设置即固定**。之后拔掉 USB 重新上电、或断电后再启动，硬件设置都保持不变。
>
> 也可以用 `电子秤资料/.../调试软件助手 使用说明书20231112-已解锁.pdf` 中介绍的图形界面工具完成上述设置（更直观）。

### 3.4 验证本程序能否正常通信

```bash
# 1. 启动本程序
python main.py

# 2. 选择与调试软件相同的 COM 口和波特率 → 点击"连接"
# 3. 状态栏应显示"已连接"，实时重量开始跳动
# 4. 放上 100g 砝码 → 应显示 ~100.0 g（±0.5g 误差内）
```

如果重量偏差较大，回到 §3.3 重新做砝码校准。

## 4. 软件架构

按层次拆分为 8 个模块，便于维护和测试：

```
serial port ──> scale_protocol (帧解析/校验/指令构造)
              ──> scale_driver   (pyserial 封装 + 模拟驱动)
              ──> calibration   (去皮/取消去皮)
              ──> weight_filter (滑动平均 + 稳定判定)
              ──> weight_state  (IDLE/WEIGHING 状态机 + 累计)
              ──> app           (Tkinter UI)
              ──> main          (程序入口 + run_as_admin)
```

| 文件 | 职责 |
|------|------|
| `config.py` | 所有可调常量（波特率、阈值、分辨率、模拟模式开关等） |
| `scale_protocol.py` | 协议层：10 字节帧构造、解析、累加和校验、粘包/拆包 |
| `scale_driver.py` | 驱动层：`ScaleDriver`（真实）+ `SimulatedScaleDriver`（虚拟） |
| `weight_filter.py` | 滤波层：滑动平均 + 稳定值判定 |
| `weight_state.py` | 业务状态机：IDLE / WEIGHING 切换、peak 跟踪、累计 |
| `calibration.py` | 会话级操作：去皮 / 取消去皮（自动处理自动发送模式启停） |
| `app.py` | Tkinter UI（主窗口、连接按钮、显示标签、粒子背景） |
| `main.py` | 入口：管理员权限请求 + 启动 Tk 主循环 |

## 5. 安装与运行

### 5.1 环境要求

- Python 3.8+
- Windows（其他系统也能跑，但 `run_as_admin` 仅 Win 有效）
- 串口硬件（CH340 USB 转 TTL 已连接电子秤）

### 5.2 安装依赖

```bash
pip install -r requirements.txt
```

### 5.3 启动

```bash
python main.py
```

Windows 上首次启动会自动以管理员权限重启（UAC 弹窗），以支持全屏与焦点抢获。

### 5.4 虚拟测试模式（无需电子秤）

适合无硬件调试：

1. 编辑 `config.py`，将 `SIMULATE_MODE_DEFAULT` 改为 `True`
2. 运行 `python main.py`
3. 点击"连接"按钮直接进入虚拟模式
4. 程序内部按 0/30g 周期生成符合协议的 10 字节帧，**所有下游逻辑（协议解析→滤波→稳定判定→状态机→累计→UI）都走真实代码路径**
5. 调试完成后改回 `False`

## 6. 使用流程（每次运行）

### 6.1 启动与连接

1. 启动 `python main.py`
2. 选择串口（CH340 对应 COM 口）→ 波特率（默认 9600）→ 点击"连接"
3. 程序弹出倒计时"请确认托盘状态已稳定，3 秒后自动去皮..."
4. 等待自动去皮完成（约 1 秒），状态栏显示"已连接 · 已去皮"
5. 放上物品即可称重；累计总重自动累加；点击"清零总重"可重置累计

> **重要**：本程序**不修改电子秤的硬件校准**，仅把当前重量视为临时零点。
> - 托盘上**带容器**时去皮 → 之后放入物品显示**净重**（推荐）
> - 托盘**空载**时去皮 → 之后放入物品显示**毛重**（也可用）

### 6.2 运行时操作

UI 底部有两个会话级操作按钮：

- **去皮（重新置零）**：把当前重量作为新的临时零点。例如中途换容器后想重新计净重。
- **取消去皮**：恢复去皮前的原始读数。

> 这两个操作**不影响**电子秤的硬件校准参数，**断电后失效**。

### 6.3 状态机逻辑

```
IDLE ──(连续2次>5g)──> WEIGHING（跟踪 peak）──(连续2次<3g)──> 累计 peak 到总重 ──> IDLE
```

- **防误触发**：进入 WEIGHING 需连续 2 次 > 5g；退出需连续 2 次 < 3g
- **峰值跟踪**：进入 WEIGHING 后记录 peak_weight（直到物品离开）
- **过滤噪声**：滤波器窗口 5（`config.FILTER_WINDOW_SIZE`）

所有阈值在 `config.py` 中可调。

### 6.4 显示策略：只显示稳定后的最终值

为避免实时重量逐级爬升/下降（如放上 30g 物品时显示 0→5→10→15→…→30，或拿开时反向逐级下降），UI **只在重量稳定后才更新显示**：

- **稳定判定**：连续 N 次（`STABLE_COUNT_REQUIRED=3`）落在阈值（`STABLE_THRESH_GRAMS=0.5`）内 → 确认稳定
- **跳变时**：保持旧稳定值不变（例如放物品瞬间 0→30 时仍显示 0；30g 稳定 3 次后才跳到 30.0）
- **物品离开时**：状态机触发"物品离开"事件 → 立即把显示强制归 0（不等 0g 重新稳定 3 次）

典型显示序列（放上 30g 物品 → 拿开）：
```
0.0  →  30.0  →  0.0
（3 次连续 30g 样本后跳到 30.0；force_set 立即归 0）
```

调参建议：
- `STABLE_THRESH_GRAMS` 越小 → 越严格（确认稳定需要的样本更接近），但响应更慢
- `STABLE_COUNT_REQUIRED` 越大 → 越稳定，但响应延迟 ≈ `100ms × N`

## 7. 通信协议概要

> 详见 `电子秤资料/.../电子秤串口模块说明书 V3.70___20240308-已解锁.pdf`

### 7.1 帧格式

所有数据均为**十六进制**。读重量帧 10 字节：

| Byte1 | Byte2 | Byte3 | Byte4 | Byte5-7 | Byte8-9 | Byte10 |
|-------|-------|-------|-------|---------|---------|--------|
| 0xAA 起始 | CMD 命令 | ADDR 地址 | SIGN 正负 | WEIGHT 24位 | CHK 校验 | 0xFF 结束 |

- **正负**：0 = 正数，1 = 负数
- **重量刻度值**：`Byte5*65536 + Byte6*256 + Byte7`（24 位无符号）
- **实际 g**：`刻度值 × 分辨率`（默认分辨率 0.1g）
- **校验**：`sum(Byte2..Byte7) == Byte8*256 + Byte9`

### 7.2 关键指令

| 指令 | 命令帧（地址=0） | 功能 | 本程序使用 |
|------|------------------|------|----------|
| 读重量 | `A3 00 A2 A4 A5` | 模块返回当前重量 | 调试用 |
| 零点校准 | `AA 00 A9 AB A8` | 取当前 AD 作为零点（永久） | **不提供**（用调试软件） |
| 去皮 | `AB 00 AA AC AD` | 临时清零（断电丢失） | ✅ 自动/手动 |
| 取消去皮 | `AC 00 AB AD AA` | 恢复去皮前基准 | ✅ 手动 |
| 砝码校准 | `AD 00 DHi DLo YY` | 写入砝码值确定分辨率 | **不提供**（用调试软件） |
| 启动自动发送（100ms） | `A4 00 A3 A5 A2` | 模块每 100ms 自动推送重量 | ✅ 连接后自动 |

> 所有命令第 5 字节均为前 4 字节的异或校验。

### 7.3 帧解析示例（手册原文）

**举例 1（正数 50g）**：

- 接收：`AA A3 00 00 00 00 32 00 D5 FF`
- 校验：长度=10 ✓，首字节=0xAA ✓，尾字节=0xFF ✓
- 累加和：`A3+00+00+00+00+32 = 0xD5 = 213`
- 期望：`00*256+D5 = 213` ✓
- 重量：`0x00*65536 + 0x00*256 + 0x32 = 50`
- 正负：Byte4=0 → 正数
- **结果：+50g**

## 8. 注意事项

- **硬件级设置**（波特率、零点校准、砝码校准）必须用厂商调试软件完成，**本程序不提供**
- 每次连接本程序后**自动去皮**（把当前重量视为 0 临时基准，断电丢失）
- 砝码重量建议 ≥ 量程 20%（≥ 200g）—— 仅供**首次硬件级校准**用
- 测量前需保证托盘状态已稳定（空载或带容器均可）
- TTL 信号传输距离 ≤ 1m（长距离请用 RS485 版本）
- 如累计总重超过 `MAX_TOTAL_GRAMS`（默认 9999g）会被钳制
- 程序启动后会自动以管理员权限重启（Windows 需 UAC 授权）

## 10. 版本历史

- **v1**（`weight_system_v2.py`，已废弃）：旧电子秤 ASCII 协议（波特率 115200，每行一个整数）
- **v2.1**：

- **v2.2**（本版）：
  - **显示策略优化**：实时重量只显示"稳定后的最终值"，不再逐级爬升/下降
  - `StableJudge` 重写：跳变时维持旧值，N 次连续稳定后才暴露新值
